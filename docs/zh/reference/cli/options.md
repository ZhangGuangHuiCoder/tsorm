# 选项与行为

每个命令接受的选项见[命令](./overview.md#命令)表，各选项逐一说明如下。

## 选项

| 选项                   | 适用命令          | 取值 / 默认值                         | 说明                                                                                                                                                                                                                                       |
| ---------------------- | ----------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `--schema <文件>`      | 全部              | `schema.orm`                          | 模型文件。迁移目录固定在它旁边的 `migrations/`；路径相对于当前目录。                                                                                                                                                                       |
| `--name <名称>`        | `migrate`         | `init` 或 `update`                    | 迁移名称 slug。非字母数字字符替换为 `_`，并加上 UTC 时间戳前缀 `YYYYMMDDHHMMSS_`。首个迁移默认 `init`，其后默认 `update`。                                                                                                                 |
| `--create-only`        | `migrate`         | 关闭                                  | 生成新迁移但不应用该新文件，同时跳过其不可执行变更检查和风险确认。此前的漂移/重置处理及已有待执行迁移仍会运行，也可生成空迁移。不希望写入目标库时使用 `diff`。                                                                             |
| `--reset`              | `migrate`、`push` | 关闭                                  | 应用或同步前先清空数据，从空库重建。未加 `--force` 时会请求确认。                                                                                                                                                                          |
| `--force`              | `migrate`、`push` | 关闭                                  | 跳过确认，接受数据丢失。                                                                                                                                                                                                                   |
| `--check`              | `deploy`          | 关闭                                  | 只读检查。数据库为最新时退出码 `0`，否则 `1`：数据库不存在、有待执行或失败的迁移、或库中某迁移在本地缺失。                                                                                                                                 |
| `--check`              | `diff`            | 关闭                                  | 只输出摘要。无差异退出码 `0`，有差异退出码 `2`。                                                                                                                                                                                           |
| `--applied <名称>`     | `resolve`         | —                                     | 将本地迁移标记为已应用，用于手动补完或已有数据库基线。不执行迁移 SQL，也不核验实际结构。名称不含 `.sql`；与 `--rolled-back` 必须且只能选一个。                                                                                             |
| `--rolled-back <名称>` | `resolve`         | —                                     | 将已有失败记录标记为已回滚，供 `deploy` 重试。必须先撤销部分变更；此选项只更新历史，不回滚 DDL。名称不含 `.sql`。                                                                                                                          |
| `--from <来源>`        | `diff`            | `migrations` \| `database` \| `empty` | 对比的起始来源，默认 `migrations`。                                                                                                                                                                                                        |
| `--to <来源>`          | `diff`            | `schema` \| `database`                | 对比的目标来源，默认 `schema`。                                                                                                                                                                                                            |
| `--out <文件>`         | `generate`        | `generated/client.ts`                 | 生成客户端的输出路径。                                                                                                                                                                                                                     |
| `--help`、`-h`         | 全部              | —                                     | 显示帮助；跟在命令后（如 `tsorm migrate --help`）时显示该命令的用法与选项。帮助文本跟随系统语言：`LC_ALL`、`LC_MESSAGES` 或 `LANG` 以 `zh` 开头时输出中文；未设置或为 `C`/`POSIX` 时回退到操作系统的界面语言；其余输出与错误码始终是英文。 |

未知的选项会直接报错。

布尔开关（`--create-only`、`--reset`、`--force`、`--check`）仅接受无值形式；`--force=false` 和 `--reset=false` 等赋值形式会被拒绝。不启用开关时应省略该参数。

## 环境变量

| 变量                            | 默认值          | 说明                                                                                                                                                          |
| ------------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DATABASE_URL`                  | `file:./dev.db` | 数据库连接；`file:`、`postgresql://` 或 `mysql://`                                                                                                            |
| `SHADOW_DATABASE_URL`           | 无              | 专用影子库，没有建库权限时使用                                                                                                                                |
| `CI`                            | 无              | 设置后不再询问，需要确认的步骤必须加 `--force`                                                                                                                |
| `LC_ALL`、`LC_MESSAGES`、`LANG` | 无              | 系统语言，按此顺序生效；以 `zh` 开头时帮助文本输出中文，未设置或为 `C`/`POSIX` 时回退到操作系统的界面语言（Linux 无桌面语言设置，保持英文），其余输出不受影响 |

## 退出码

| 退出码 | 含义                                                |
| ------ | --------------------------------------------------- |
| `0`    | 成功                                                |
| `1`    | 出错；`deploy --check` 发现数据库不是最新时也返回 1 |
| `2`    | `diff --check` 发现差异                             |

## 交互

重置数据库和数据丢失的确认只在交互终端中询问。非交互环境（标准输入或输出不是终端，或设置了 `CI`）中，需要确认的步骤会报 `NON_INTERACTIVE`，加 `--force` 可以跳过确认。
